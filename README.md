## 📌 Sobre o Projeto

O **Mi Calc** é um projeto de desenvolvimento web que visa recriar a interface minimalista, responsiva e intuitiva da calculadora padrão dos dispositivos Xiaomi (MIUI/HyperOS). 

O foco é entregar uma experiência visual agradável e funcional diretamente no navegador.

---

## 🎨 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da aplicação.
- **CSS3**: Estilização inspirada na MIUI, com visual limpo e moderno.
- **JavaScript (Vanilla JS)**: Lógica das operações matemáticas e manipulação de eventos no DOM.
- **Google Material Symbols**: Ícones nativos para ações da calculadora.

---

## 🛠️ Funcionalidades Atuais

- [x] Interface minimalista estilo Xiaomi.
- [x] Operações aritméticas básicas (Adição, Subtração, Multiplicação e Divisão).
- [x] Limpeza de tela (`C`) e função apagador (`Backspace`).
- [x] Entrada de números decimais.

## 💻 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/InasAlmeida/calculadora.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd calculadora
   ```

3. Abra o arquivo `index.html` no seu navegador favorito.
